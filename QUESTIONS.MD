Контрольные вопросы

1. Чем класс отличается от объекта?
Ответ: 
    Класс — это шаблон (чертёж), который описывает свойства и методы. Объект — это конкретный экземпляр класса, созданный по этому шаблону с помощью оператора new.

2. Для чего нужен конструктор и когда он вызывается?
Ответ: 
    Конструктор (__construct) нужен для задания начального состояния объекта (инициализации свойств). PHP вызывает его автоматически в момент создания объекта оператором new.

3. Что означает $this и почему он недоступен в статических методах?
Ответ: 
    $this — это ссылка на текущий объект внутри его методов. В статических методах объект не создаётся (метод принадлежит самому классу, а не экземпляру), поэтому $this внутри них недоступен.

4. Чем отличается $obj2 = $obj1 от $obj2 = clone $obj1?
Ответ: 
    При $obj2 = $obj1 обе переменные ссылаются на один и тот же объект в памяти (изменения в одном видны в другом). При $obj2 = clone $obj1 создаётся независимая копия объекта.

5. Чем статическое свойство отличается от обычного? Как к нему обратиться?
Ответ: 
    Статическое свойство принадлежит всему классу и является общим для всех его объектов. Обычное свойство принадлежит конкретному объекту. Обращение к статическому свойству происходит через имя класса и двойное двоеточие: ClassName::$property (или self::$property внутри класса).

6. Что такое readonly-свойство и когда его можно присвоить?
Ответ: 
    Это свойство, доступное только для чтения. Его можно инициализировать (присвоить значение) только один раз — обычно в конструкторе. После инициализации изменить его нельзя, PHP выдаст ошибку.

7. Что такое продвижение свойств в конструкторе?
Ответ: 
    Это синтаксис в PHP 8, позволяющий объявлять свойства класса прямо в параметрах конструктора, добавляя к ним модификатор доступа (например, public string $name). PHP автоматически создаст свойство и присвоит ему переданное значение.

8. Как реализовать цепочку вызовов методов?
Ответ: 
    Нужно, чтобы каждый метод, участвующий в цепочке, возвращал ссылку на текущий объект (return $this; или return static;). Тогда можно вызывать следующий метод сразу после предыдущего: $obj->method1()->method2().

9. Назовите три магических метода и случаи, когда PHP их вызывает.
Ответ: 
    __construct (вызывается при создании объекта), __toString (вызывается при попытке привести объект к строке, например, через echo), __call (вызывается при обращении к несуществующему методу объекта).

10. Чем protected отличается от private при наследовании?
Ответ: 
    protected свойства и методы доступны как внутри самого класса, так и внутри классов-наследников. private доступны только внутри того класса, где они объявлены, классы-наследники не имеют к ним доступа.

11. Что делает ключевое слово final?
Ответ: 
    Запрещает переопределение. Если final указан перед методом, его нельзя переопределить в классе-наследнике. Если final указан перед классом, от него нельзя наследоваться.

12. Как работает spl_autoload_register?
Ответ: 
    Эта функция регистрирует пользовательскую функцию-загрузчик. Когда PHP встречает в коде неизвестный класс, он по очереди вызывает все зарегистрированные загрузчики, передавая им имя класса. Загрузчик должен проверить имя и подключить нужный файл через require.

13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?
Ответ: 
    PSR-4 задаёт соответствие между префиксом пространства имён и базовой директорией. Оставшаяся часть пространства имён (после префикса) превращается в путь к файлу, где обратные слеши \ заменяются на прямые /, а к имени файла добавляется расширение .php (имя файла должно совпадать с именем класса).

14. Когда нужно выполнять composer dump-autoload?
Ответ: 
    Эту команду нужно выполнять после изменения файла composer.json (особенно секции autoload), а также при добавлении новых классов или изменении структуры папок, чтобы Composer перестроил карту автозагрузки.
